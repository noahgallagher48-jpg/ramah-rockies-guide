Printing

Every frame in this library prints. The size on each card is a ceiling, not a gate. The smallest file here still makes a clean 10″ print and every one of them is safe on a book page. The only thing that changes between frames is how large you can go.

SubstrateResolution usedWhat it is for
Metal and acrylic300 DPIHard, reflective surfaces show detail, so these get the most resolution. Lobby and donor-wall pieces.
Photographic paper250 DPIFramed prints, gifts, anything behind glass.
Canvas150 DPIThe weave absorbs detail, so canvas goes largest for the same file. Big wall pieces on a budget.

Every size on this page is figured on a 2:3 ladder, so none of them need a crop. Sizes are given short edge first. Where a frame needs something specific, it says so on the card in orange.
