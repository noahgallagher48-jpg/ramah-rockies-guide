Printing

Every frame in this library prints. The size on each card is a ceiling, not a gate. The smallest file here still prints past eight inches on its short edge, and every one of them is safe on a book page. The only thing that changes between frames is how large you can go.

SubstrateResolution usedWhat it is for
Metal and acrylic300 DPIHard, reflective surfaces show detail, so these get the most resolution. Lobby and donor-wall pieces.
Photographic paper250 DPIFramed prints, gifts, anything behind glass.
Canvas150 DPIThe weave absorbs detail, so canvas goes largest for the same file. Big wall pieces on a budget.

Every size on this page is that frame's own shape at that resolution, so nothing is cropped to reach it. Short edge first. Not every frame is the same shape: most are 3:2, some are 4:5, a few are wide or square, and the sizes shown account for that. Where a frame needs something specific, the card says so.

Which file to reach for. Both are in sRGB, so the colour is right everywhere. Take the Web file for your website, email, social and slides: same picture, around 1MB, quick to send. Take the Full res file for print, for the book, and for anything a designer is going to open. Nothing needs converting and nothing needs asking us first.
